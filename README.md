# منصة ذكية متكاملة لرصد السيول والزلازل
## Smart Civil Defense Platform

### الوصف
منصة ويب متقدمة مخصصة لرصد ومراقبة السيول والزلازل في الوقت الفعلي، مع توفير تنبيهات فورية وتوقعات دقيقة ومحاكاة هيدرولوجية. المنصة قابلة للربط مع بيانات NASA و Google Earth Engine.

### المميزات الرئيسية

#### 1. **لوحة المراقبة اللحظية**
- عرض حالة جميع الأودية المراقبة
- مؤشرات الخطر في الوقت الفعلي
- رصد الزلازل والمعلومات الزلزالية
- متوسط شدة الأمطار الحالية

#### 2. **ملفات الأودية**
- بيانات مفصلة لكل وادي
- تاريخ السيول والأحداث السابقة
- مستويات الخطر حسب حساسية كل وادي

#### 3. **نظام التنبيهات الذكي**
- تنبيهات فورية للحالات الحرجة
- سجل شامل لجميع التنبيهات
- تصنيف التنبيهات حسب النوع والمستوى

#### 4. **توقعات الأمطار**
- توقعات أسبوعية
- رسوم بيانية توضيحية
- إمكانية الربط مع نماذج الطقس العالمية

#### 5. **محاكاة السيول**
- محاكاة تدفق السيول بناءً على كمية الأمطار
- تقييم الخطر المتوقع
- توصيات الطوارئ

#### 6. **الإعدادات المتقدمة**
- إعدادات ربط NASA APIs
- إعدادات Google Earth Engine
- نظام الصلاحيات والأدوار

### الأدوار المدعومة

1. **مستخدم عادي** - عرض المعلومات العامة فقط
2. **مراقب ميداني** - إدخال ملاحظات من الميدان
3. **غرفة العمليات** - مراقبة شاملة وتنبيهات
4. **مدير النظام** - إدارة كاملة والإعدادات المتقدمة

### التثبيت والتشغيل

#### المتطلبات
- Python 3.8+
- pip

#### الخطوات

1. **استنساخ المستودع**
```bash
git clone https://github.com/joorygassim42-cell/smart-civil-defense-platform.git
cd smart-civil-defense-platform
```

2. **تثبيت المكتبات**
```bash
pip install -r requirements.txt
```

3. **تشغيل التطبيق**
```bash
streamlit run app.py
```

4. **فتح المتصفح**
سيفتح تلقائيًا على `http://localhost:8501`

### التكامل مع الخدمات الخارجية

#### NASA APIs
- **GPM IMERG** - بيانات الأمطار بدقة عالية
- **MODIS** - بيانات التصوير المرئي
- **SRTM DEM** - نماذج الارتفاع الرقمية

#### Google Earth Engine
- تحليل الانحدار (Slope Analysis)
- حساب تدفق المياه (Flow Direction)
- تحديد الأودية تلقائيًا
- تحليل تغير الأراضي
